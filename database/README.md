# Папка database

Ця папка містить SQL-ресурси для відновлення бази даних ShvydkoFoodDb без додавання бінарних файлів (`.mdf`, `.ldf`, `.bak`).

## Файли

- `schema.sql` — структура таблиць бази даних.
- `seed.sql` — приклад стартових даних: категорії, налаштування, мінімальний admin.

## Як відновити базу даних

1. Створіть порожню базу даних `ShvydkoFoodDb` у SQL Server.
2. Виконайте `database/schema.sql` для створення таблиць.
3. Виконайте `database/seed.sql` для початкових даних.
4. За потреби запустіть серверний seed-скрипт у `server`:
   ```bash
   cd server
   npm run seed
   ```

## Зауваження

- Не додавайте до GitHub файли `*.mdf`, `*.ldf`, `*.bak`, `*.trn`.
- Для повного наповнення таблиці `Products` рекомендується використовувати серверний `seed.ts`.
